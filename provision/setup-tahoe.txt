# Phantom — macOS Tahoe (26) Setup Assistant automation
#
# Drives a freshly-installed macOS through Setup Assistant via VNC keystroke
# injection and OCR clicks, all the way to a logged-in desktop with the
# phantom-agent installed. After this, the host controls the VM over vsock
# (`phantom vm exec`) and finishes configuration with provision.sh.
#
#   phantom vm boot-script <vm-id> --file provision/setup-tahoe.txt
#
# Prerequisite: stage the agent into the shared folder first, so the guest can
# install it from /Volumes/phantom-shared:
#
#   cd phantom-agent && ./init-host-shared-folder.sh
#
# Screens are matched by on-screen text, so exact button coordinates don't
# matter, but timings assume a cold first boot. Setup Assistant wording differs
# between macOS versions — this script targets Tahoe 26.x. Note: in the guest,
# Alt maps to the Command key. Creates a local admin account phantom/phantom.

# Language: the list defaults to 日本語 (top). Move down one to English and
# confirm; macOS reloads in English and advances to the country picker.
<wait60s><down><wait2s><enter><wait15s>

# Select Your Country or Region — type to filter, then Continue
united states<wait2s><click 'Continue'><wait3s>

# Transfer Your Data to This Mac — start clean
<click 'Set up as new'><wait1s><click 'Continue'><wait3s>

# Written and Spoken Languages — accept region defaults
<click 'Continue'><wait3s>

# Accessibility — skip
<click 'Not Now'><wait3s>

# Data & Privacy
<click 'Continue'><wait3s>

# Create a Mac Account — full name, (auto) account name, password x2.
# Then uncheck "reset password with Apple Account" so no Apple sign-in is forced.
<click 'Full Name'>phantom<tab><tab>phantom<tab>phantom<wait1s>
<click 'Allow computer'><wait1s>
<click 'Continue'><wait30s>

# Sign In to Your Apple Account — skip; confirm the "are you sure" sheet
<click 'Set Up Later'><wait2s><click 'Skip'><wait5s>

# Terms and Conditions — Agree, then confirm the sheet (exact-match OCR keeps
# these off the adjacent "Disagree" button)
<click 'Agree'><wait2s><click 'Agree'><wait5s>

# Welcome — enter the desktop (a virtualized Tahoe install skips the
# Location/Analytics/Siri screens that appear on real hardware)
<click 'Get Started'><wait20s>

# Open Terminal via Spotlight
<leftAltOn><spacebar><leftAltOff><wait2s>Terminal<wait2s><enter><wait8s>

# Mount the host shared folder and install the agent. sudo reads the password
# from stdin; the first access to the virtiofs volume triggers a TCC prompt.
echo phantom | sudo -S mkdir -p /Volumes/phantom-shared && echo phantom | sudo -S mount_virtiofs phantom-shared /Volumes/phantom-shared && sudo /Volumes/phantom-shared/install.sh<enter><wait5s>
<click 'Allow'><wait10s>

# The phantom-agent is now running as a launchd daemon. From here the host
# drives the VM over vsock:
#   phantom vm exec <vm-id> -- sh /path/to/provision.sh   (see provision.sh)
